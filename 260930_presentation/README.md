# Agentic Coding Overview slides

Slides by Cédric Jung and Jozef Janus for 30 September 2026, based on the files in `../documentation/` and the ACIN Beamer template in `../presentation_template/`.

Build with:

```bash
cd 260930_presentation
latexmk main.tex
```

The PDF is generated at `build/main.pdf`. It includes one result slide for each of six benchmarks: GDPval-AA v2.1, DeepSWE v1.1, Terminal-Bench 4.0, Terminal-Bench 2.1, Humanity's Last Exam, and GPQA Diamond. The title and content slides include clickable source links. Model availability, access details, prices, and benchmark results are a dated snapshot; check the linked sources and the live AQUEDUCT `/v1/models` endpoint before reuse.
